# Features

✅ Core Requirements

## 1. Search for artworks by:

- Keyword (e.g., “Monet”, “self-portrait”, “flower”)
- Medium (e.g., “Oil on canvas”, “Photograph”)
- Century or culture (e.g., “18th century”, “Japanese”)

## 2. List results with:

- Thumbnail
- Title
- Artist name
- Date
- Artwork detail view:
  - High-resolution image
  - Description
  - etc.
- Link to museum page

## 3. Bookmark artworks locally (via localStorage)

## 4. Responsive design (mobile + desktop)

# Nice to Have (fine if not achieved)
- Autocomplete on search input
- Infinite scroll or pagination
- Filter by availability of images
- Ability to "randomize" and discover a new artwork
- Dark mode

# 🧠 What You Should Demonstrate

- Thoughtful component structure
- REST API integration (with real-world quirks like missing images or incomplete metadata)
- Error and loading state handling
- State management decision-making
- Code style and separation of concerns
